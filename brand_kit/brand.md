# Fonts
Fonts can be found in `fonts/` folder

## Font Family
`Montserrat` is used for titles,  both online and in print documentation
`Open sans` is used for body text, both online and in print documentation.

## Usage
`Montserrat Medium` for Headings
`Open Sans Bold` for subheadings
`Open Sans Regular` for most text
`Open Sans Bold Uppercast` for callouts like flags or banners
`Font Awesome` Icons
